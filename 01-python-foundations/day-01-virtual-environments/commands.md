# Commands Used

## Create Virtual Environment

```bash
python -m venv venv
```

## Activate

### Windows CMD

```bash
venv\Scripts\activate
```

### PowerShell

```powershell
.\venv\Scripts\Activate.ps1
```

## Check Python Version

```bash
python --version
```

## Check Installed Packages

```bash
pip list
```

## Freeze Packages

```bash
pip freeze > requirements.txt
```

## Deactivate

```bash
deactivate
```
