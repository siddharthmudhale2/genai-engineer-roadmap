# What is Python?

## Definition

Python is a high-level, interpreted, general-purpose programming language widely used in web development, automation, Artificial Intelligence, Machine Learning, Data Science, and backend development.

---

## Why Python for Generative AI?

Python has one of the largest AI ecosystems.

Libraries:

- NumPy
- Pandas
- PyTorch
- TensorFlow
- Transformers
- LangChain
- FastAPI

are all Python-first.

---

## What is a Virtual Environment?

### Definition

A virtual environment is an isolated Python environment that allows each project to maintain its own Python interpreter, installed packages, and dependencies without affecting other projects on the same system.
