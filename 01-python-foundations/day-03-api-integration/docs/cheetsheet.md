## 📖 Quick Definitions

| Concept | Definition |
|---|---|
| **API** | An interface that allows software applications to communicate with each other. |
| **HTTP Request** | A message sent by a client to a server asking for data or an operation. |
| **HTTP Response** | The server's response to an HTTP request. |
| **`requests`** | A Python HTTP client library used to communicate with web servers and APIs. |
| **GET** | HTTP method commonly used to retrieve data. |
| **POST** | HTTP method commonly used to submit data or create a resource. |
| **Query Parameter** | Optional information added to a URL to filter or customize a request. |
| **HTTP Header** | Metadata sent with an HTTP request or response. |
| **Response Object** | Python object returned by `requests` containing response information. |
| **Timeout** | Maximum amount of time the application waits for a response. |
| **`raise_for_status()`** | Raises an exception when an HTTP response indicates a client or server error. |
